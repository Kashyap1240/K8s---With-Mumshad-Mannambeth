## 🧪 Practice Lab: ReplicaSets (Commands Reference)

A quick-reference set of commands used while practicing ReplicaSet creation, inspection, and troubleshooting.

---

**1. Check how many ReplicaSets exist on the system**
```bash
kubectl get replicaset
# or
kubectl get rs
```

**2. Check the image used by pods in a specific ReplicaSet (e.g. `new-replica-set`)**
```bash
kubectl describe replicaset new-replica-set
```
> Look under the `Pod Template` → `Containers` section for the `Image:` field.

**3. Check how many pods are `READY` in `new-replica-set`**
```bash
kubectl get replicaset new-replica-set
```
> The `READY` column shows `<current>/<desired>` pods ready.

**4. Delete one of the pods directly (out of the existing 4)**
```bash
kubectl get pods
kubectl delete pod <pod-name>
```
> 📌 Since a ReplicaSet always tries to maintain the desired count, it will **automatically create a new pod** to replace the deleted one.

**5. Create a ReplicaSet from a definition file**
```bash
kubectl create -f /root/replicaset-definition-1.yaml
```

**6. Check the correct `apiVersion` for ReplicaSet before creating it**
```bash
kubectl api-resources | grep replicaset
```
> This confirms the API group/version supported by your cluster (should show `apps/v1`). Helps avoid the `no matches for kind "ReplicaSet"` error.

Then create it:
```bash
kubectl create -f /root/replicaset-definition-1.yaml
```

**7. Delete multiple ReplicaSets (e.g. `replicaset-1` and `replicaset-2`)**
```bash
kubectl delete replicaset replicaset-1
kubectl delete replicaset replicaset-2
```
> Or, if you have their definition files:
```bash
kubectl delete -f replicaset-1.yaml
kubectl delete -f replicaset-2.yaml
```

---

### 🚀 Cheat Sheet — Useful ReplicaSet Commands
| Command | Purpose |
|---|---|
| `kubectl get rs` / `kubectl get replicaset` | List all ReplicaSets |
| `kubectl describe replicaset <name>` | Full details: image, replicas, selector, events |
| `kubectl api-resources \| grep replicaset` | Check correct apiVersion for ReplicaSet |
| `kubectl create -f <file>.yaml` | Create a ReplicaSet from file |
| `kubectl delete replicaset <name>` | Delete a ReplicaSet by name |
| `kubectl delete -f <file>.yaml` | Delete a ReplicaSet using its definition file |
| `kubectl delete pod <name>` | Delete a pod (ReplicaSet auto-recreates it) |
