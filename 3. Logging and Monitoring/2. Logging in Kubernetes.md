# 📜 Logging in Kubernetes

## 1. Logging in Docker (Baseline) 🐳

- App writes events to **stdout/stderr**; Docker captures them.
- Demo container: `event-simulator` (generates random web-server-style events).

```bash
# Run detached: logs are NOT shown on the terminal
docker run -d kodekloud/event-simulator

# View logs
docker logs <container-id>

# Live log trail
docker logs -f <container-id>
```

---

## 2. Logging in Kubernetes: Single-Container Pod ☸️

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: event-simulator-pod
spec:
  containers:
    - name: event-simulator
      image: kodekloud/event-simulator
```

```bash
# View logs
kubectl logs event-simulator-pod

# Stream live (same as docker logs -f)
kubectl logs -f event-simulator-pod
```

- Logs are **per container**, scoped to the container inside the pod.

---

## 3. Multi-Container Pods ⚠️

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: event-simulator-pod
spec:
  containers:
    - name: event-simulator
      image: kodekloud/event-simulator
    - name: image-processor
      image: some-image-processor
```

- `kubectl logs <pod>` **fails** with multiple containers; you must specify the container.

```bash
# Specify container explicitly with -c
kubectl logs -f event-simulator-pod -c event-simulator
```

---

## 4. Useful `kubectl logs` Flags 🧰

| Flag | Purpose |
|---|---|
| `-f` | Stream logs live |
| `-c <container>` | Select container in a multi-container pod |
| `--tail=<N>` | Show only the **last N lines** |
| `--since=<duration>` | Logs newer than a relative time (`30s`, `5m`, `2h`) |
| `--since-time=<RFC3339>` | Logs after an absolute timestamp |
| `--timestamps` | Prefix each line with its timestamp |
| `--previous` (`-p`) | Logs of the **previous (crashed/restarted)** container instance |
| `--all-containers=true` | Logs from every container in the pod |
| `--prefix` | Prefix each line with pod/container name |
| `-l <label-selector>` | Logs from all pods matching a label |
| `-n <namespace>` | Target namespace |
| `--limit-bytes=<N>` | Cap output size |

---

## 5. Collecting Logs into a File 💾

### `--tail` explained

- `--tail=<N>` returns only the **last N lines** of the log (like Unix `tail -n`).
- Default: **`-1` (all lines)** for a single pod; when using `-l <selector>` the default is **10**.
- Combine with `-f` to **start from the last N lines and keep streaming**.

```bash
# Last 100 lines
kubectl logs event-simulator-pod -c event-simulator --tail=100

# Last 100 lines, then keep streaming
kubectl logs -f event-simulator-pod -c event-simulator --tail=100
```

### Redirect to a file (`>` overwrite, `>>` append)

```bash
# Overwrite: snapshot of the last 100 lines
kubectl logs event-simulator-pod -c event-simulator --tail=100 > event-simulator.log

# Append: accumulate across runs
kubectl logs event-simulator-pod -c event-simulator --tail=100 >> event-simulator.log
```

### Stream live to the terminal AND a file (`tee`)

```bash
kubectl logs -f event-simulator-pod -c event-simulator --tail=100 | tee event-simulator.log
```

### File naming conventions 🏷️

Encode **namespace, pod, container, timestamp** in the filename so files stay traceable.

```bash
# Pattern: <namespace>_<pod>_<container>_<YYYY-MM-DD_HHMMSS>.log
kubectl logs event-simulator-pod -c event-simulator -n default --timestamps \
  > default_event-simulator-pod_event-simulator_$(date +%F_%H%M%S).log
```

| Component | Example value |
|---|---|
| Namespace | `default` |
| Pod | `event-simulator-pod` |
| Container | `event-simulator` |
| Timestamp | `$(date +%F_%H%M%S)` → `2026-11-21_143005` |

### Crashed container: capture the previous instance

```bash
kubectl logs event-simulator-pod -c event-simulator --previous \
  > event-simulator_previous_$(date +%F_%H%M%S).log
```

### Every container in a pod, one file each

```bash
POD=event-simulator-pod
for C in $(kubectl get pod $POD -o jsonpath='{.spec.containers[*].name}'); do
  kubectl logs $POD -c $C --timestamps > ${POD}_${C}_$(date +%F_%H%M%S).log
done
```

### All pods matching a label, one file

```bash
kubectl logs -l app=event-simulator --all-containers=true --prefix --tail=200 \
  > app-event-simulator_$(date +%F_%H%M%S).log
```

## 🚀 Summary Cheat Sheet

- **Docker:** `docker logs [-f] <container-id>`.
- **K8s:** `kubectl logs [-f] <pod>`; logs are **per container**.
- **Multi-container pod:** must pass **`-c <container>`**, otherwise the command errors.
- **`--tail=N`** → last N lines; default is all (`-1`), or 10 with `-l`.
- **To file:** `>` overwrite, `>>` append, `| tee` for live view + file.
- **Filename pattern:** `<namespace>_<pod>_<container>_<timestamp>.log` via `$(date +%F_%H%M%S)`.
- **Crash debugging:** `--previous`.
- **Next level:** centralized logging stacks (third-party / EFK / ELK integrations).
